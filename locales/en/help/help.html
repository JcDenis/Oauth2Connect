Providers
Each block configures one third party service (Google, Github, Slack, Auth0, Amazon). Create an application on its console (link "Application console"), set the callback URL given in the rules, then copy the application key and secret here. The domain is only used by Auth0 and must start with https://.
Disable and enable
"Disable" hides a provider on the public side and keeps its settings. "Enable" puts it back.
Public side
A button is added to the Frontend session widget and to the account page of connected members. A member must first link their account from the account page.
